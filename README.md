Site estático pronto para GitHub, Vercel, Netlify ou hospedagem própria.

## Publicação na Vercel

1. Envie todo o conteúdo desta pasta para a raiz de um repositório no GitHub.
2. Importe o repositório na Vercel.
3. Selecione **Other** como framework.
4. Não informe comando de build.
5. Mantenha o diretório de saída como `.` e publique.

O pixel, o checkout, as imagens e os depoimentos já estão incluídos localmente.
